Model comparison

Zero return, past-only expanding mean, a pre-specified momentum rule and ridge. P&L comparisons do not equalize exposure or risk. Sharpe is descriptive and unadjusted for serial correlation or model selection; zero-position Sharpe is undefined. Max drawdown uses compounded equity.

Uncertainty intervals

Moving-block bootstrap of the realized test series. Conditional on the model and this short historical sample. It does not include training uncertainty or repair post-hoc research choices.

Regularization

λ minimizes validation MSE and is then frozen. The selected λ = 100 lies at the upper grid boundary; it is not a claim of global optimality. Features are standardized using only each fit's training history.

Results by test window

Expanding training history; refit every 20 test sessions. Short windows are noisy and are not independent experiments.

Feature ablation

Drop one feature, refit on past data, retain the full-model λ and position rule. ΔMSE = ablated minus full model: negative means omission improves error. Exploratory diagnosis, not a new holdout.

Trading-cost sensitivity

One-way cost applies to both entry and exit through gross turnover. Market impact remains additional.

Training & test timeline

Six features observed through close t predict open-to-close return on t+1. Position = clip(prediction / 1%, −1, +1). Enter at the next open; fully exit at that day's close. No shuffled cross-validation.

This is a retrospective engineering demonstration on an already available sample. The chronological test was held out from model fitting and λ selection; it is not a preregistered, prospective test.

Execution model

Q = A · τ / N
I(A) = Y · σ · √(Q / ADV)
r(A) = αdelay − c − k√A

A is capital; τ is daily gross turnover (buys + sells); N is the number of equal-weight, equally liquid instruments. σ is daily volatility, ADV is daily dollar volume. Y is assumed, not estimated from fills.

c = 252τ(spread/2 + fee)/10,000.
k = 252τYσ√[τ/(N·ADV)].

Delayed edge = α · 2−(D−1)/(2h), using mean delay (D−1)/2 and signal half-life h. A simplifying scenario assumption.

Capacity & optimal capital

Azero = [(αdelay − c)/k]²
Aliq = p · N · ADV / τ
A* = min(4Azero/9, Aliq)

For αdelay > c, the model's usable capacity is min(Azero, Aliq). If the edge does not cover fixed costs, positive capacity is zero.

The unconstrained maximum follows from differentiating Π(A) = A(αdelay − c) − kA3/2. Maximum dollars arrive before zero net return.

For recurring flows, dividing a daily order over more days does not reduce steady-state daily turnover. The simulator therefore does not grant artificial liquidity from a longer schedule.

Limitations

Statistical limits

One equity, two historical years and 164 test sessions. No cross-asset validation, prospective performance, survivorship correction or deployment claim. Public sample data is not a point-in-time institutional feed. Adjusted price features and execution-price conventions need a production data audit.

Execution limits

Daily volume is not auction liquidity. Equal liquidity hides bottlenecks. Impact is a stylized square-root approximation, especially unreliable at high participation. Funding, stock borrow, taxes, correlated trades and execution latency are omitted.

Annualized returns use arithmetic averages. The ML demo uses a zero cash benchmark; its reported return is not risk-adjusted alpha. Bootstrap intervals quantify conditional sampling variation, not the probability that a strategy will work.
